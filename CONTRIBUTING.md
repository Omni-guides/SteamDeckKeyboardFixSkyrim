# Contributing

Thank you for your interest in Steam Deck Keyboard Fix for Skyrim.

## Issues and suggestions

Bug reports, compatibility results and suggestions are welcome through GitHub
Issues. When reporting a problem, include your Skyrim version, SKSE version and
the contents of `SteamDeckKeyboardFixSkyrim.log` where possible.

## Pull requests

This project is currently maintained as a solo-maintainer project. Pull
requests will only be considered when the maintainer has specifically asked
someone to submit one. Unsolicited pull requests will be closed.
